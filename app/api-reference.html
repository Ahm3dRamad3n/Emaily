Every endpoint documented here is pulled directly from the current backend. Base URL throughout: https://BASE-URL/{endpoints}

Field names and route structures below are exact. Response JSON casing follows standard ASP.NET Core conventions (camelCase) but hasn't been captured from a live response for every endpoint — verify shapes against your running API before building strict client-side parsing around them.

Authentication

POST /api/auth/register Public

Creates an account. Requires a valid email-verification token obtained from POST /api/auth/send-verification-email first. On success, auto-creates a Free-plan subscription.

Request body

{ "email": "sara@example.com", "password": "••••••••", "verificationToken": "..." }

Response 201 Created

{ "message": "Account created." }
POST /api/auth/login Public

Authenticates with email and password. Returns a 10-minute HS256 access token and a 7-day refresh token.

Request body

{ "email": "sara@example.com", "password": "••••••••" }

Response 200 OK

{ "accessToken": "eyJ...", "refreshToken": "..." }
POST /api/auth/refresh-token Public

Exchanges an unused, unrevoked, unexpired refresh token for a new access/refresh pair. The old refresh token is marked used and cannot be exchanged again — each refresh rotates the token.

Submissions

POST /api/submit/{publicApiKey} Public · anonymous

Queues a submission for delivery. Anonymous, CORS allows all origins, rate-limited to 10 requests/minute per IP, 3 MB body limit. Processed asynchronously — the response confirms the submission was accepted, not that the email was delivered.

Request body

Field Type Notes
templateId string Required. A t_… template ID.
privateKey string A sec_… key. Required for BackendOnly projects, forbidden for FrontendOnly.
recipientEmail string Optional, backend-mode only.
recipientName string Optional, backend-mode only.
recaptchaToken string Required if the template has reCAPTCHA v2 enabled.
appCheckToken string Required if the template has App Check enabled.
fields object Key/value pairs filling the template's {{variables}}.

Response on success

{ "message": "The email has been successfully queued." }

Error responses

Status Cause
400 Rendered HTML body was empty after variable substitution.
403 Invalid private key, Origin not in the allowed domains, failed reCAPTCHA/App Check, or unsafe HTML rejected by the sanitizer.
404 Public API key doesn't match any project.
429 Rate limit exceeded (10/min/IP). 
curl -X POST \
  https://BASE-URL/submit/pub_9f2a... \
  -H "Content-Type: application/json" \
  -d '{"templateId":"t_contact_form","fields":{"name":"Sara","message":"Hi!"}}'
fetch("https://BASE-URL/submit/pub_9f2a...", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    templateId: "t_contact_form",
    fields: { name: "Sara", message: "Hi!" }
  })
})
  .then((res) => res.json())
  .then((data) => console.log(data));
GET /api/projects/{id}/submissions Auth required

Returns paged submission history for a project. Each entry includes status (Pending, Sent, Failed, Resent, Discarded, or QuotaExceeded).

POST /api/submissions/{id}/retry Auth required

Re-queues a failed submission for delivery. Blocked for submissions that were already sent, or that came from a template with privacy mode on (their payload was never stored, so there's nothing to retry).

Projects

GET /api/projects Auth required

Lists every project owned by the authenticated user.

POST /api/projects Auth required

Creates a project and issues its pub_… / sec_… key pair. Blocked once you're at your plan's project limit.

PUT /api/projects/{id}/access-mode Auth required

Switches a project's access mode between FrontendOnly, BackendOnly, and Hybrid — see Access modes in the docs for what each mode enforces on the submit endpoint. 

curl -X PUT \
  https://BASE-URL/projects/p_xxxx/access-mode \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"accessMode":"Hybrid"}'
fetch("https://BASE-URL/projects/p_xxxx/access-mode", {
  method: "PUT",
  headers: {
    "Authorization": "Bearer YOUR_ACCESS_TOKEN",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ accessMode: "Hybrid" })
});

The body field name above (accessMode) follows this API's camelCase convention but wasn't given verbatim in the backend summary — confirm it matches your actual DTO before relying on it.

Templates

GET /api/projects/{id}/templates Auth required

Lists every template belonging to a project.

POST /api/projects/{id}/templates Auth required

Creates a template. The HTML content is capped at 3 MB and is blocked once you're at your plan's template limit for that project.
